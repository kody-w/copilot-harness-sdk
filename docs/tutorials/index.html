The Copilot Studio ladder

Each rung turns RAPP agent.py files and SKILL.md skills into one published Copilot Studio agent on the GitHub Copilot harness, then proves it with real prompts. Every rung is reproducible from this repo alone, and every published agent keeps working with no RAPP brainstem behind it.

What every rung has in common

  • One build, one deploy. scripts/deploy-harness-agent.mjs imports a workspace as a solution, provisions connection references and flows, binds tools, publishes and verifies. The tutorial script adds the proven infrastructure profiles for agents that match them.
  • Proof, not a demo. A turns file of prompts and regular expressions is sent to the published agent over the SDK's copilot-studio-3p route (a delegated user token) and the answers are recorded. The proof files live next to each rung.
  • No brainstem at runtime. Once published, the agent is an ordinary Copilot Studio solution. The manual way imports the exported solution with pac alone.
